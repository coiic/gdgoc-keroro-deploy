# GDGoC CNU 팀 모집 사이트 — 개인 수정본

원본: [ppre1ude/gdgoc-keroro-deploy](https://github.com/ppre1ude/gdgoc-keroro-deploy)

이 저장소는 원본의 `cc36dc91560b6b9991baa13c2e2f855172fb426f` 배포본을 내려받아 수정한 스냅샷입니다. 원본의 변경 이력을 포함한 GitHub fork는 아닙니다. 원본 저자 표시와 암호화된 HTML을 유지했습니다.

## 변경 사항

- 네 팀 카드에 케로로·타마마·쿠루루·도로로 기본/동작 이미지 추가
- 바스트샷 배치, 마우스 hover 및 키보드 focus 시 0.3초 전환
- 움직임 줄이기 설정 지원
- 신청서 조회 실패 시 데이터 보존 및 저장·수정 중단
- 계정 삭제 오류 확인
- 신청 순위 충돌 시 자동 순위 변경 대신 안내
- 신청서만 저장되고 미배정 선택 저장이 실패한 경우 부분 성공 안내

이미지 전환은 현재 네 팀의 `data-slug`에 연결되어 있습니다. 새 팀의 캐릭터를 자동 배정하는 기능은 아닙니다.

## 검증

Node.js로 다음 명령을 실행합니다.

```sh
node --test tests/regression.test.cjs
```

오류 상황을 가정한 함수 단위 테스트 9개를 포함합니다. 네 캐릭터의 기본·동작 이미지 전환은 로컬 브라우저에서 확인했습니다. 실제 운영 데이터베이스 연동 검증은 하지 않았습니다.

## 실행 및 제한

HTML은 공용 암호로 보호되어 있습니다. 내부 화면을 보려면 기존 암호가 필요합니다. 이미지와 스타일 경로가 `/gdgoc-keroro-deploy/`로 시작하므로 해당 경로를 제공하는 정적 서버가 필요합니다.

Supabase SQL 및 암호화 전 원본 생성 코드는 이 배포본에 포함되어 있지 않습니다. 서버 트랜잭션과 데이터베이스 접근 정책은 별도로 점검해야 합니다.

작업 중 공유했던 미리보기는 외부 연결을 차단하는 별도 서버를 사용했습니다. 이 저장소의 파일만 다른 서버에 배포하면 그 차단 정책이 자동 적용되지 않습니다. 기능 테스트에는 별도 테스트 데이터베이스 또는 모의 응답을 사용하세요.
